# Demo video script (target about 8 minutes; the limit is 10)

Record the screen with **Xbox Game Bar** (Win + G, then the record button) or OBS, with your microphone on. Run the app first (`uvicorn speechlens.app:app --port 8000`, open http://localhost:8000; for everything except the microphone segment the live site https://rishinavroop22.github.io/speechlens/ works too) and keep this script on your phone. Speak slowly; it is fine to pause and cut later. Upload to YouTube as **Unlisted**, with English audio.

| Time | On screen | Say |
|---|---|---|
| 0:00-0:30 | Title slide or the app's empty Analyze page | "Judging spoken performance is subjective. Two judges hear the same speech and give different scores, and the speaker gets vague feedback like 'work on your pacing'. SpeechLens finds exactly where a delivery goes wrong, measures by how much, and explains why, reproducibly." |
| 0:30-1:30 | Dataset tab: scroll the five source speeches, then the clip table filtered to one speech | "There's no public dataset of good versus bad delivery of the same text, so we built one. Five public-domain presidential speeches are our gold standard: Roosevelt, Kennedy, Johnson, Reagan and Obama. For each, we generate the same words delivered badly: eleven flaw types, rushed, dragging, monotone, trailing off, missing pauses, awkward pauses, fillers, mumbling and stutters, plus two reading errors, skipped words and restarted phrases, each at five severities from almost perfect to egregious." |
| 1:30-2:15 | Dataset table: filter Flaw = Filler, then Kind = Control | "The flaws are injected with PSOLA resynthesis in the speaker's own voice, so every label is exact to the sample. We also recorded ourselves performing scripted flaws for a real-world test, and added controls: the same speech shifted four semitones up or down, or twelve decibels quieter. A fair system must report nothing on those." |
| 2:15-3:45 | Analyze tab: click a mixed-flaw clip (level 5). Point at the truth bar, the bands, a finding; click "Play this part" then "Play the reference here" | "Here's a clip with five injected flaws. The top bar is ground truth, which the system never sees. The colored bands are what SpeechLens found. Both readings are force-aligned word by word with wav2vec2, then compared on pitch, loudness, articulation and timing, with the reference warped onto the participant's timeline. Pitch is in semitones relative to each speaker's own voice, so a deep and a high voice are compared fairly. Click a finding: rushed delivery from 12.3 to 15.8 seconds, articulation 56 percent faster than the reference, four times the speaker's normal variation. Listen to the participant... and the reference at the same words." |
| 3:45-4:20 | Same finding: click **Hear it fixed**, then **Play this part** again | "And this is the part we're proudest of. 'Hear it fixed' plays the participant's own voice with only the cause we named changed, here the speed moved back to the reference rate. If our explanation is right, fixing that one variable should make the flaw disappear. We tested exactly that over 73 flaws: re-analysing the repaired audio, the finding vanished in 90 percent of cases. The explanation isn't a guess; we can intervene on it." |
| 4:20-4:45 | Click a "Restarted phrase" sample (sidebar), open the finding | "It also catches reading errors. Here the reader went back and said 'to our Secretary of' twice. The evidence line shows what the recogniser heard in that spot, so you can check it yourself." |
| 4:45-5:20 | Change the Rubric dropdown from Declamation to Extemporaneous; show the score change. Open a filler or stutter finding | "Every finding becomes a rubric score. Different events weight dimensions differently: declamation rewards vocal variety, extemporaneous rewards fluency. No language model writes the explanations: they are filled from measured values, so the same audio always gives the same result." |
| 5:20-5:45 | Scroll to **Coach's summary**: priorities, drills, voice quality; click **Print / save as PDF** | "Every analysis ends with a coach's summary: the top priorities with a drill for each, a voice-quality profile, and a report you can print or send." |
| 5:45-6:30 | Analyze: click **Record with microphone**, read two sentences of the Kennedy text with one deliberate long pause and a rushed phrase, stop, Analyze (local app only) | "You can also just record yourself. I'll read Kennedy, with a long pause in the middle and one rushed phrase... and it finds both, in my voice, against Kennedy's delivery. Now I click 'Practice this part', read the rushed sentence again properly... and it tells me it's fixed, with the before and after numbers." |
| 6:30-7:40 | Evaluation tab: KPIs, grounding table, then the ablation table, the stress test, the counterfactual table | "We evaluate the full pipeline on raw audio, cross-validated. Flaws are located with F1 0.70 and a median boundary error of 156 milliseconds, and unflawed speech, even shifted four semitones, draws 0.03 false findings per minute. Why does the reference matter? Remove it and the same detector drops from 0.72 to 0.08 F1, and still only 0.16 if we tune it on the answers. We stress-tested it too: MP3, telephone audio, echo and a ten percent tempo change barely matter; background noise does, so the app measures it, compensates partly and warns. And the counterfactual table shows fixing the named cause removes the finding." |
| 7:40-8:10 | README on GitHub, then the app | "Everything runs on a CPU with one command, and the code, the dataset and the documentation are on GitHub. That's SpeechLens." |

Tips: zoom the browser to 110 % so text is readable in the video; close other tabs; do one dry run first.
