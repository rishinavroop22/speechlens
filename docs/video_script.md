# Demo video script (target 6-7 minutes)

Record the screen with **Xbox Game Bar** (Win + G, then the record button) or OBS, with your microphone on. Run the app first (`uvicorn speechlens.app:app --port 8000`, open http://localhost:8000) and keep this script on your phone. Speak slowly; it is fine to pause and cut later. Upload to YouTube as **Unlisted**, with English audio.

| Time | On screen | Say |
|---|---|---|
| 0:00-0:30 | Title slide or the app's empty Analyze page | "Judging spoken performance is subjective. Two judges hear the same speech and give different scores, and the speaker gets vague feedback like 'work on your pacing'. SpeechLens finds exactly where a delivery goes wrong, measures by how much, and explains why, reproducibly." |
| 0:30-1:30 | Dataset tab: scroll the five source speeches, then the clip table filtered to one speech | "There's no public dataset of good versus bad delivery of the same text, so we built one. Five public-domain presidential speeches are our gold standard: Roosevelt, Kennedy, Johnson, Reagan and Obama. For each, we generate the same words delivered badly: nine flaw types, rushed, dragging, monotone, trailing off, missing pauses, awkward pauses, fillers, mumbling and stutters, each at five severities from almost perfect to egregious." |
| 1:30-2:15 | Dataset table: filter Flaw = Filler, then Kind = Control | "The flaws are injected with PSOLA resynthesis in the speaker's own voice, so every label is exact to the sample. We also recorded ourselves performing scripted flaws for a real-world test, and added controls: the same speech shifted four semitones up or down, or twelve decibels quieter. A fair system must report nothing on those." |
| 2:15-4:15 | Analyze tab: click a mixed-flaw clip (level 5). Point at the truth bar, the bands, a finding; click "Play this part" then "Play the reference here" | "Here's a clip with five injected flaws. The top bar is ground truth, which the system never sees. The colored bands are what SpeechLens found. Both readings are force-aligned word by word with wav2vec2, then compared on pitch, loudness, articulation and timing, with the reference warped onto the participant's timeline. Pitch is in semitones relative to each speaker's own voice, so a deep and a high voice are compared fairly. Click a finding: rushed delivery from 12.3 to 15.8 seconds, articulation 56 percent faster than the reference, four times the speaker's normal variation. Listen to the participant... and the reference at the same words." |
| 4:15-5:00 | Change the Rubric dropdown from Declamation to Extemporaneous; show the score change. Open a filler or stutter finding | "Every finding becomes a rubric score. Different events weight dimensions differently: declamation rewards vocal variety, extemporaneous rewards fluency. No language model writes the explanations: they are filled from measured values, so the same audio always gives the same result." |
| 5:00-5:45 | Analyze: upload one of your own team recordings (take C or D) against its reference | "Here's one of our own recordings with scripted flaws. A different voice, a phone microphone, and real human flaws, and it still finds the mumbled sentence and the filler." |
| 5:45-6:30 | Evaluation tab: scroll the KPIs, grounding table, severity heat map, controls, score chart | "We evaluate the full pipeline on raw audio. This table shows how precisely flaws are located; this one shows detection climbing with severity, as it should; the controls show it stays quiet on unflawed speech in a different voice; and the overall score falls steadily as delivery gets worse. Re-running gives byte-identical output." |
| 6:30-7:00 | README on GitHub, then the app | "Everything runs on a CPU with one command, and the code, the dataset and the documentation are on GitHub. That's SpeechLens." |

Tips: zoom the browser to 110 % so text is readable in the video; close other tabs; do one dry run first.
